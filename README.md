# Vegetarian Social

Ứng dụng cộng đồng ăn chay dùng React/Vite, Express và PostgreSQL.

## Quy ước phát triển chung

Bắt đầu với [development guide](docs/development-guide.md). Khi làm UI, tra [UI Kit](docs/skill-ui-kit.md) và source component; các quy tắc chung được duy trì tại hai tài liệu này.

## Bản đồ source

| Vị trí | Vai trò |
|---|---|
| `client/` | Frontend chính |
| `server/` | Backend chính |
| `client_template/`, `server_template/` | Mã tham khảo; xác nhận source đang chạy trước khi chọn file sửa |
| `database-seed/` | SQL và hướng dẫn đi kèm |
| `docs/` | Hướng dẫn và tài liệu chung |

Thiết lập database theo [hướng dẫn kết nối local](docs/db-connect-tutorial.md).
